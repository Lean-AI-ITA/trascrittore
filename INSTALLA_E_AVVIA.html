Benvenuto nel Setup Wizard
Questo wizard ti guiderà nell'installazione di tutti i componenti necessari per eseguire il Trascrittore Video & Audio sul tuo PC Windows.
⚡ Da chiavetta USB — funziona senza internet installato
📁 Contenuto della chiavetta
📁 TRASCRITTORE_USB/ ├── INSTALLA_E_AVVIA.html ← sei qui ├── trascrittore.py ├── 0.CONTROLLO_PYTHON.bat ├── 1.CREA_AMBIENTE_PULITO.bat ├── 2.INSTALLA_WHISPER.bat ├── 3.AVVIO_TRASCRITTORE.bat └── ffmpeg.exe da scaricare
🗺️ Cosa faremo
  • Passo 2 — Python · Verifica se Python è installato, altrimenti ti dà il link diretto
  • Passo 3 — Ambiente virtuale · Crea un ambiente isolato per le dipendenze
  • Passo 4 — Whisper · Installa il motore AI di trascrizione di OpenAI
  • Passo 5 — FFmpeg · Scarica il convertitore audio/video
  • Passo 6 — Avvio · Lancia il trascrittore con un doppio click
💡
Nota: Copia prima la cartella dalla chiavetta sul Desktop (es. C:\Users\TuoNome\Desktop\Trascrittore). Lavorare direttamente dalla chiavetta è più lento e potrebbe causare errori.
Tempo stimato: 5–15 minuti
🐍
Passo 2 — Verifica Python
Python è il motore del trascrittore. Versione minima richiesta: 3.8+
🔍 Verifica veloce — apri il file .bat
✅
Fai doppio click su 0.CONTROLLO_PYTHON.bat nella cartella. Se vedi "Python trovato!" puoi passare al passo successivo.
🔍 Verifica manuale (alternativa)

Premi Win+R, scrivi cmd, premi Invio. Poi incolla questo comando:

python --version

Dovresti vedere qualcosa come Python 3.11.x

📥 Python non installato? Scaricalo qui
🐍
Python — Sito Ufficiale
python.org/downloads · Windows 64-bit · Gratis

⚠️
IMPORTANTE durante l'installazione:
Nella prima schermata spunta "Add Python to PATH" prima di cliccare "Install Now".
Senza questo spunto, nulla funzionerà!
🔄
Dopo l'installazione di Python, riavvia il PC e poi torna qui.
📦
Passo 3 — Crea l'Ambiente Virtuale
L'ambiente virtuale isola le dipendenze del trascrittore dal resto del PC. Va creato una sola volta.
⚡ Metodo rapido — usa il file .bat
✅
Fai doppio click su 1.CREA_AMBIENTE_PULITO.bat. Aspetta che finisca e poi torna qui.
🖥️ Metodo manuale (se il .bat non funziona)

Apri il Prompt dei comandi nella cartella del trascrittore e digita:

python -m venv trascrittore_env

Comparirà una nuova cartella trascrittore_env/ — è normale.

💡 Come aprire cmd nella cartella giusta
  1. Apri la cartella Trascrittore in Esplora File
  2. Clicca sulla barra dell'indirizzo in alto
  3. Scrivi cmd e premi Invio
  4. Si aprirà il terminale già nella cartella giusta ✅
🤖
Passo 4 — Installa Whisper AI
Whisper è il motore di intelligenza artificiale di OpenAI per la trascrizione vocale. Richiede connessione internet una sola volta.
⚡ Metodo rapido — usa il file .bat
✅
Fai doppio click su 2.INSTALLA_WHISPER.bat. L'installazione scarica ~500MB e può richiedere 5-10 minuti.
🖥️ Metodo manuale

Esegui questi comandi in sequenza nel terminale:

trascrittore_env\Scripts\activate
pip install openai-whisper
python -c "import whisper; print('OK')"

L'ultimo comando deve stampare OK — se lo vedi, Whisper è installato correttamente.

⚠️
Connessione necessaria: L'installazione scarica Whisper da internet (~300MB). Assicurati di avere una connessione attiva. Dopo l'installazione, il programma funziona offline.
⏱️
La prima trascrizione scaricherà anche il modello AI (~150MB). Le trascrizioni successive saranno immediate.
🎬
Passo 5 — Scarica FFmpeg
FFmpeg converte i video in audio prima della trascrizione. Serve un solo file .exe da mettere nella cartella.
📥 Scarica FFmpeg
🎬
ffmpeg-release-essentials.zip
gyan.dev · Windows 64-bit · ~80MB · Gratis
↓ 🐙
ffmpeg-master-latest-win64 (alternativo)
GitHub · BtbN/FFmpeg-Builds · Windows 64-bit · Gratis
↓
📋 Come installare ffmpeg.exe
  1. Scarica il file .zip
  2. Aprilo con Esplora File (click destro → Estrai tutto)
  3. Naviga in: ffmpeg-...\bin\ffmpeg.exe
  4. Copia solo il file ffmpeg.exe
  5. Incollalo nella cartella del Trascrittore (dove c'è trascrittore.py)
✅
Dopo aver copiato ffmpeg.exe nella cartella, puoi procedere all'avvio!
🎉
Tutto pronto!
Il Trascrittore è configurato e pronto all'uso.
🚀 Come avviare il Trascrittore
✅
Metodo più semplice: Fai doppio click su 3.AVVIO_TRASCRITTORE.bat

Oppure da terminale:

trascrittore_env\Scripts\activate && python trascrittore.py
📋 Checklist finale
  • Python installato e nel PATH
  • Cartella trascrittore_env/ presente nella cartella
  • Whisper installato correttamente
  • ffmpeg.exe nella stessa cartella di trascrittore.py
🔧 Risoluzione problemi comuni
  • "python" non riconosciuto → Riavvia il PC dopo aver installato Python
  • Errore ambiente virtuale → Cancella la cartella trascrittore_env e riesegui il passo 3
  • Trascrizione vuota → Verifica che il video abbia audio. Prova prima con un file MP3.
  • FFmpeg non trovato → Controlla che ffmpeg.exe sia nella stessa cartella di trascrittore.py
  • Prima trascrizione lenta → È normale: sta scaricando il modello AI (~150MB)
